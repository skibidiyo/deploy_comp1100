Interviewer:
So, do I have your consent for a short interview today?

Participant:
Yes.

Interviewer:
Thank you so much. So, I'm just going to start with the first question. Basically, all these questions are about my project, which is developing an app that helps students make new friends. So these are going to be related to that.
My first question is: have you heard or used any apps like Tinder or Mumble?

Participant:
No.

Interviewer:
Okay, so imagine an app like that, but not for dating—for making new friends. Would you be interested in something like that?

Participant:
Probably not.

Interviewer:
Probably not, okay.
How important is it to you to know someone's interests or hobbies before you try to connect with them?

Participant:
Not that important. I usually just find those things out by talking to them naturally.

Interviewer:
Okay, okay. So you don’t need their interests to be specific with yours to be friends with them?

Participant:
Some similarity might be nice, but I don’t necessarily need a really specific common interest. If it’s something general, like we’re both into movies, we can share things about that. There are bound to be some similarities.

Interviewer:
Okay, thanks. What kind of things on a profile would make you feel comfortable enough to start a conversation?

Participant:
If I was on those kinds of apps, I would say maybe some common interests. Like I said before, I don’t necessarily need them, but in an online scenario it might make it easier to start an interaction.

Interviewer:
No, I’m not asking about interests—more like age, background, or general info. What kind of things would you like to see on a profile?

Participant:
Yeah, like common interests. For online interactions, I would prefer that. But it isn’t a necessity. I wouldn’t really care for in-person interactions, but for online ones, knowing interests might be helpful because it indicates whether I’d get along with the person.

Interviewer:
Okay, cool. What kind of group size would you feel more comfortable in when meeting new people? One-on-one or a group?

Participant:
I’d say two to three people.

Interviewer:
So you prefer a group setting rather than individual?

Participant:
Individual is fine, but it’s more interesting with an extra person. It’s easier for conversations to fizzle out with just two people. If one person is a bit off that day, it can be hard to recover.

Interviewer:
Okay, cool. Do you find it helpful when there’s something to talk about already, like a shared topic or prompt?

Participant:
If it’s forced, I wouldn’t like that. If it’s natural, then yes. For example, if you join a club, there’s already a shared context—you can ask why someone joined. But online, pre-written topics feel kind of forced since the only context is the app itself.

Interviewer:
Alright. Would you be open to a fun activity or game as a way to get to know someone new before meeting in person?

Participant:
What kind of activity?

Interviewer:
It could be a text-based game, like browser games on Discord.

Participant:
I know what those are, but I haven’t used them. So you’re suggesting one of them?

Interviewer:
Not forcing—just an option.

Participant:
If it helps social connection, then yeah. But if it’s something like chess, that might be counterproductive. If it helps me get to know the other person better, then it would be good.

Interviewer:
Would knowing about nearby campus events related to your interests help you meet new people?

Participant:
Sorry, can you repeat that?

Interviewer:
The app would notify you about upcoming campus events. Would you like that?

Participant:
If you can integrate that, it would be pretty good. Especially if friends you made on the app are also attending. It would be useful if the app notified you so you could meet up there.

Interviewer:
So you think it’s a good feature?

Participant:
Yeah.

Interviewer:
Final question: what would make this app better than something like Instagram? Any downsides of apps you currently use?

Participant:
Not major ones. Instagram is mainly for texting back and forth, which is fine. One downside is Reels—it can be distracting. But I doubt your app would include that, so it’s not a big issue.

Thank you so much. That’s all the questions I have for today.
